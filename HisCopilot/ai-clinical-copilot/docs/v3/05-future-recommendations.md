# 象元 AI 诊疗 v3 — 后续建议（按优先级）

> 这些是**已知缺口**与**投入产出比最高的下一步**，不是已完成的功能。排序依据：对患者安全/合规的影响 > 对日常使用的影响 > 工程质量。

## P0 — 正式用于真实患者之前必须完成

1. **导入真实药品字典并由药剂科核对规则库。**
   当前药品目录含"示例/通用参考"条目（界面已显式标注），安全规则（十八反/十九畏、妊娠禁忌、剂量范围、过敏类别、药物相互作用、剂量格式）是**有限的通用规则**，`server/safety/data/reference.py`（版本 `xy-safety-2026.10.1`）需要执业药师/中医师审阅与增补；"规则未命中"绝不等于安全。建议：药品目录批量导入（含院内编码、规格、剂型、药理分类、过敏原类别、妊娠分级、成人剂量范围），规则变更走版本号 + 变更记录。
2. **全链路 HTTPS + 对外访问控制。**
   患者手机在 HTTP 下不能直接录音（已降级为"调用手机录音"）；账号/会话 Cookie 在 HTTPS 下才带 `Secure`。建议在前置 Nginx/现有 3443 代理上终止 TLS、限制管理端只在内网可达、对 `/api/v1/p/*` 单独限流（应用内已有基础限流）。
3. **真实环境的备份与恢复演练。**
   迁移前自动备份、`cli backup`、`cli restore` 都已实现并验证；但**异机/异地备份、保留策略、定期恢复演练**需要运维落实。附件目录 `data/objects_v3/` 也要纳入备份。
4. **隐私与合规：** 附件与数据库静态加密、患者同意书版本留存、数据保留/删除策略、审计日志导出与定期校验（`verify-audit` 可放入定时任务）。
5. **在真实手机/真实网络上做一轮现场验收。** 本次浏览器验证用的是桌面 Chrome（含虚拟麦克风与手机视口），**没有**在真实手机、真实弱网上验证。

## P1 — 显著提升临床价值

6. **RAG 知识库**（目前 0 片段，v3 如实提示"无证据可引用"）：导入指南/教材/院内规范，检索结果以 `E1…En` 编号进入提示词，沿用现有"引用必须存在"的校验机制。
7. **真实 HIS 适配器：** 现有 `submit_mock_his` 是唯一出口；对接前先约定幂等键、失败重试、回执字段、撤销/作废的同步语义，并保持"必须医师显式操作"。
8. **结构化剂量录入：** 目前西药单次剂量是自由文本 + 格式校验（警告）。改为"数值 + 单位"控件后，才能做单次/日剂量上限、肝肾剂量调整等硬规则。
9. **检验结果趋势与参考范围：** 同一患者历次检验对比、按性别/年龄的参考范围；OCR 结果仍须逐项核对。
10. **ASR/OCR 提速：** 当前为 CPU 版 llama.cpp（ASR ≈1 秒、OCR ≈11 秒）；GPU 版需另行编译，且不得影响 GPU0（ComfyUI）的分配。
11. **电子签名（CA）与正式打印模板：** 现在是系统内的签名哈希 + 版本；医院通常需要符合规范的电子签章与固定版式。
12. **随访触达：** 目前由医师生成患者链接；可接入合规的短信/企业微信通道发送提醒（仍需医师启用计划）。

## P2 — 工程与运维

13. **可观测性：** 任务耗时/失败率/队列深度指标与告警（数据已在 `jobs`/`job_events`，缺看板）；模型服务不可用时的主动通知。
14. **多进程/多机：** SQLite + 进程内 worker 适合单诊所；扩展需要换 PostgreSQL，并把任务队列外置（领取逻辑已是"条件 UPDATE"，迁移成本可控）。
15. **性能与压力测试：** 并发已用真实并发测试覆盖了关键写路径，但尚未做持续压测与长稳测试（尤其是 27B 串行队列下多医师同时起草方案的排队时间）。
16. **无障碍与小屏医师端：** 患者端为手机优先；医师端以桌面为主，窄屏与键盘可达性未系统审查。
17. **多语言/术语：** ICD-10 与中医证候标准术语的联想输入、诊断编码校验。
18. **旧系统退役：** 确认 v3 稳定后，按运行手册做切换（停旧服务、`import-legacy` 重新导入最新数据、改端口/反向代理），旧库作为只读归档保留。**切换会改变现有用户访问的服务，需要您确认时间窗口。**

## 已知限制（v3 当前行为，非缺陷）

- 病历定稿后，若药房退回处方且医师重签，病历快照不会自动更新，需医师手动"更正"（界面有提示）。
- 单进程部署；两个 API 进程同时写同一个库不受支持。
- 旧版数据导入为时间点快照：导入之后旧系统新增的数据不会自动同步（切换时需重新导入）。
- `XY_AI_MODE=fake` 仅用于自动化测试，返回带标记的固定内容，**禁止在生产启用**（管理员"运行状态"页会显示"测试替身"）。
